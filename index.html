Eight simulations, all driven by real equations

Nothing is animated by hand: every frame is computed from Coulomb’s law, Ohm’s law, the Biot–Savart-style dipole field or Faraday’s law. Change an input and the physics re-solves.

Physics inside the code
  • E = kq/r2, superposition by vector sum
  • Req for series, parallel and mixed
  • Φ = μ0ma2/[2(a2+z2)3/2]
  • r = mv/(|q|B), T = 2πm/(|q|B)
Works everywhere

Pure HTML, CSS and JavaScript. Tested in Chrome, Firefox and Edge on desktop, and on touch screens down to 320 px wide. Progress is stored locally — no account, no server, no tracking.

Ohm’s lawV = I·RV, A, ΩVoltage drives current against resistance
